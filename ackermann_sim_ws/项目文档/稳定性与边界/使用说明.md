## 只看复现计划：一条命令

在Ubuntu普通终端、任意目录运行：

```bash
bash ${ACKERMANN_WS}/scripts/run_route_stability.bash --dry-run
```

用途：读取预定9项场景。它自动加载现有Jazzy/工作区，只打印计划，不启动仿真，不安装软件、不改系统配置。正常看到JSON场景；异常保留最早报错，检查工作区install/setup.bash是否存在，不要盲目重装。

## 重跑全部测试：另一步，一条命令

先关闭其他域84的粗路网仿真，再执行：

```bash
bash ${ACKERMANN_WS}/scripts/run_route_stability.bash
```

正常自动逐场干净启动、测试和退出，逐次显示START/DONE。含录像、录包、完整复核，需数分钟并占用磁盘；原始数据规模约1–2GB/批。输出使用新的时间批次名，写入M3过程记录和验证报告/运行日志，不覆盖本轮验收。任一主/补充判据失败即停止后续扩展，保留现场记录；不要手动发速度绕过失败。

每次实验的说明.md解释文件用途。原始数据/bag不能手改内部名称；build/install/log为自动生成，日常可跳过。归档脚本的历史绝对路径仅描述当时过程位置，不需篡改原日志。

## 单独启动，不要盲目换参数

沿用scripts/start_route.bash与request_route.bash。紧弯：start:=B，route_params参数指向src/ackermann_route/config/stability/tight_route.yaml，终点5；连续分支：start:=A，roads与graph参数分别指向continuous_roads.yaml和continuous_graph.geojson，终点5。封路需map_updates:=true，并由验证工具创建墙和发布更新；只启动Gazebo不会凭空产生新增障碍。

所有完整参数与启动日志保存在对应实验配置快照与scenario.json；快照含当次/tmp路径，仅用于审阅，不直接当启动文件。源码是唯一可编辑参数源。

限幅是将转得过急的请求压到车体可执行范围。本轮保护器保留，终点约20cm容差未放宽，未将仿真转弯/制动当作真实车体参数。扩大到300m仍需测规模性能与长路线切换，校园和实车仍未验收。
