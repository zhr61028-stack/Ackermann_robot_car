## 重新执行

只有需要重新验证时才运行，查看结果不需要。任何目录（例如终端默认的~）可执行下面一条命令：

```bash
bash ${ACKERMANN_WS}/scripts/run_route_long_distance.bash --dry-run
```

它自动读取ROS环境，只打印100m和两个310m场景计划，不发车、不录包。若提示文件不存在，先核对项目根目录是否迁移；若ROS缺包，保留报错，不自行安装或改系统。主目录目前为/home/zhanghaoran/.codex/.chatgpt-projects/Ackermann_robot_car。

确认电脑空闲且没有另一个84域仿真实例后，完整复现：

```bash
bash ${ACKERMANN_WS}/scripts/run_route_long_distance.bash
```

自动先100m，全程复核通过后再两次310m；预期30–40分钟及数GiB新增录包，各记录名带新时间，不覆盖当前证据。运行时能看到Gazebo/RViz，车辆自主行驶；不要用键盘或其他终端发速度/目标。启动失败或任一判据失败，批量流程停止，过程记录与日志保留。Ctrl+C中断本批次并关闭它启动的程序，未完成记录不能当通过。无需sudo，无安装或系统配置修改。当前录制完整关键topic；并非所有辅助topic全集。

正常最终三个DONE all_pass=True。日志在验证报告/运行日志/长距离_时间，重跑数据先存实验记录/M3_导航/过程记录；复核并整理后才能称最新验收成果。默认启动脚本源码/配置原名保留，不从报告快照运行程序。
