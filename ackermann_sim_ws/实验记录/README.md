## 目录与文件用途

每个实验包含说明.md；按现有文件创建演示视频/、轨迹或分析图/、测试结果/、原始数据/。无视频或无图的实验不创建空类别。固定文件名demo.mp4、results.json、bag等保留为实验内部兼容链接，真实数据按中文类别存放，不产生第二份录包。

M1只有旧版本过程记录；M2里程计与定位、M4安全冗余、M5双目替换尚无独立对应验证记录，本轮未创建目录。车辆反馈/真值导航不能冒充M2；停车及接触传感器测试不能冒充M4整条安全链。

新实验写入所属阶段的过程记录/下一个未存在的新目录；通过复核后才归验收成果。不要运行绘图/固定目标检查脚本覆盖已有证据。
