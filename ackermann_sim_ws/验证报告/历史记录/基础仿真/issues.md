# 仿真问题与处理记录

| 现象 | 依据与原因 | 最小处理及结果 |
|---|---|---|
| 首次误在父目录构建 | 构建日志同时出现 M0 包 | 将本轮新生成产物保留移至 /tmp，改在独立工作区构建；未修改参考文件 |
| rosdep 无法解析 ament_python | 官方 Python 示例只将其写为 build_type | 移除错误 buildtool_depend，补齐实际运行依赖；依赖检查通过 |
| 观察节点启动失败 | AttributeError 显示 publishers 为 Node 只读属性 | 将自有变量改名 path_publishers；重新启动验证 |
| 录像未找到 RViz | 实际窗口标题包含配置路径 | 按程序类名和本项目配置定位窗口 |
| 测试消息序列化退出 | ROS Vector3 字段要求浮点数，脚本传入整数零 | 将脚本所有速度/角速度显式转 float；关闭遗留专用录包进程 |
| 普通窗口截图被聊天窗口遮挡 | 检查录像帧发现不是仿真画面 | 弃用并清空该次录像内容；使用 XComposite 应用 backing pixmap，仅读取程序自身画面；最终画面已检查 |
| XGetImage pixmap 的 RGB masks 为零 | 独立 pixmap 没有 Visual，不能直接使用图像 masks | 从所属 app window 的真实 Visual 获取格式；非支持格式拒绝录像，不回退桌面采集 |
| 录像时现场订阅漏掉首个超时事件 | 现场计算 605 ms，完整 rosbag 首次事件实际为 305 ms，节点最大 tick 间隔约 10 ms | 改为录包关闭后解析完整 bag；最后得到约 305 ms 输出停车、492 ms 实际静止，保留旧诊断与原日志 |
| 原生轮里程计与物理真值累积偏差 | 稳定圆弧 odom 半径 2.477 m、真值 2.50 m；源码使用前轮角平均近似曲率 | 记录约 20 cm 最大偏差，不重写成熟控制插件，不冒充真实定位精度 |
| Gazebo EGL/DRI 警告 | 仍能显示车辆，物理真值与控制验证正常 | 未修改显卡驱动，实际画面与运动证据均保留 |

未通过或未验证：实车动态制动/MCU 硬停/全链路失联、真实参数、轮胎噪声模型、Wayland 录像、完整导航。未知硬件参数保持待确认。
