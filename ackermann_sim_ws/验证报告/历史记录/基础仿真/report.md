# 阿克曼最小仿真准备与验证报告

项目状态：M0 开发环境与通用仿真已完成，硬件盘点待补。本轮完成不依赖实物的阿克曼车辆基础仿真，不包含自主导航、路网或实车验收。

## 实现与选择

复用 Gazebo Harmonic 8.15.0 随包提供的官方 ackermann_steering.sdf 示例及原生 AckermannSteering 控制插件，使用现有 ros_gz_bridge 和 robot_state_publisher。无需安装新软件或下载 Fuel 模型。车辆采用简化四轮、前轮转向、后轮驱动；前轮自由滚动，后轮左右轮速由原生组件按转弯半径计算。

车辆几何、动力学假设和控制限制集中在 src/ackermann_sim/config/vehicle.yaml。生成器同时生成 SDF、URDF 和桥接配置，使轮位置与控制组件的轴距/轮距一致。原始官方示例保留在 vendor/，附 Apache-2.0 许可证与来源 SHA256。自写运行节点仅为仿真指令保护和轨迹观察，不重写车辆物理控制器，不含 MCU 协议。

## 控制接口与阿克曼约束

/cmd_vel 接收 geometry_msgs/msg/Twist：linear.x 是前后速度 v；angular.z 是期望车身偏航角速度 ω。保护节点把合法、限幅后的指令发布到 /sim/cmd_vel，桥接到 /model/ackermann/cmd_vel，由原生控制插件转成左右后轮速度与两个前轮转角。

非零速度时半径 R=v/ω，中央等效转角 δ=atan(L/R)。正 ω 前进时左转，负 ω 前进时右转。内侧前轮转角更大。保护节点根据 Rmin=L/tan(δmax) 限制 |ω|≤|v|/Rmin；零速度时角速度也置零，因此原地旋转指令被拒绝。非有限值和非平面分量被拒绝。

原生插件使用 Rmin=L/sin(plugin_steering_limit)。为与配置中的中央等效转角统一，生成器设置 plugin_steering_limit=asin(tan(δmax))，本配置约 0.436525 rad。并检查最大内轮转角不超过关节限制。不能把这两个转角限制参数直接当作同一个量。

原生插件保留最后一条 Twist；保护节点接收指令超时后持续输出零速度。判断依据是接收时刻，不是上游发送时刻，Twist 没有源时间戳。若保护节点本身崩溃或整个上位机断连，本轮没有独立硬件保护。这不是实车底盘驱动或完整安全链。

## 坐标与观察

TF：odom → base_footprint → base_link → 转向关节与四轮。base_footprint 位于后轴中心的地面投影；base_link 高度为轮半径。插件独占 odom→base_footprint；robot_state_publisher 根据实际关节消息发布车体内部关系，避免重复发布同一 TF。

/odom 为原生轮式里程计；/ground_truth/poses 为 Gazebo 独立物理模型位姿，仅用于验证，不广播到 /tf，也不冒充定位算法。模型初始平面位置和航向为零，因此其世界平面坐标与初始 odom 对齐。RViz 蓝色为轮里程计轨迹，绿色为实际模型轨迹。

## 验证结果

本轮测试先规定基础检查容差，再执行；这些容差属于仿真检查配置，不是任务书实车验收标准。

| 检查 | 结果 |
|---|---|
| 独立包编译、依赖检查、统一启动 | 通过，无新增系统安装 |
| 前进与显式停车 | 通过，实际位置前进，停车后保持静止 |
| 左右转弯与转向关节 | 通过，左右航向变化和内外轮角关系正确 |
| 原地旋转指令 | 通过，实际位置和航向不变 |
| 速度与曲率限幅 | 通过，超限 0.9 m/s 被限制到 0.6 m/s |
| odom 和 TF | 通过，检查车体及四轮链路，odom 与 TF 平面位置差为 0 |
| 指令中断保护 | 通过，完整 rosbag 记录实际触发及后续物理停止 |
| 视频与 rosbag | 36.9 s H.264 视频，369 帧全部解码成功；MCAP 数据完整可读取 |

正常左右转弯：v=0.5 m/s、ω=±0.2 rad/s，期望半径 2.50 m，实际稳定圆弧拟合约 2.50 m。左转前轮角约 0.342 / 0.283 rad，右转约 -0.283 / -0.342 rad，内轮绝对角度更大。

最大转角测试：理论后轴中心最小半径约 1.892 m，实际稳定圆弧约 1.892 m。该值只属于当前假设模型，不能填作实车 Hybrid-A* 的实测转弯半径。

原生轮里程计稳定圆弧半径约 2.477 m，最大转角圆弧约 1.864 m，整段轨迹与物理真值最大位置差约 0.200 m。源码采用左右前轮角平均值估算曲率，产生近似误差。方向与 TF 一致不等于高精度定位通过；后续融合与导航必须重新验证，未为此重写原生算法。

## 超时触发与车辆停止 分别计时

计时基准为保护节点最后一次收到命令的单调时钟。最终计时来自独立 rosbag 录制进程保存的完整消息，避免录像进程订阅回调漏采样。车辆速度由独立模型位置差分得到，不使用轮里程计作为实际停止证据。

| 事件 | 从最后一次收到命令起的约测时间 |
|---|---|
| 保护输出零速度 | 305 ms |
| 实际模型达到静止阈值 | 492 ms |
| 持续静止 200 ms 后确认 | 692 ms |

静止阈值：速度低于 0.02 m/s，偏航角速度低于 0.02 rad/s，并连续保持 0.2 s。不是精确速度为零的硬实时测量。模型位姿名义采样间隔 20 ms，另有消息传输和时钟映射误差。保护触发后到物理静止约 187 ms，主要包含插件减速过程。

本结果不能称为“300 ms 内停车”，也不满足或替代任务书的实车安全故障注入验收。物理仿真仍正常减速，实际硬件制动、上位机断连与独立 MCU 硬停均未验证。
